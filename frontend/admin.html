Admin

Choose which skills the assistant may use, and what it remembers for each workspace. Skills run only on the models on this machine.

Admin password

The one set as ADMIN_PASSWORD in backend/.env on the server.

Agent skills

A skill is offered to the model only when a message needs it: a picked database, a request for a chart, or something to remember. Changes apply to the next message.

Memories

Short facts given to the model in every chat of a workspace: names, preferences, decisions. Until the app has logins, everyone using a workspace shares its memories.

One fact per memory, up to 500 characters.
