Databases

Connect a database here, then pick it in the chat's model menu and ask about its data. A model on this machine looks at the tables and runs read-only queries to answer.

How it is kept safe

  • Only queries that read are run. Anything that could change the database is refused before it is sent, and the connection itself is opened read-only.
  • Only models on this machine are used. Rows never go to a cloud model.
  • Passwords stay on the server, in backend/data/sql/. They are never sent back to this page.
  • Still, give the app a database user that can only read.
